# LoLShorts 사용자 가이드

LoLShorts를 설치하고 사용하는 방법을 단계별로 설명합니다.

> **준비 상태 안내:** 이 가이드는 현재 구현 및 제품 방향을 설명하지만, 실제 LoL/리플레이 동작, YouTube 계정 업로드, GPU/오디오 캡처, Windows 설치/업데이트, 지원 워크플로는 현장 검증 전까지 공개 준비 상태로 주장할 수 없습니다. 결제, Toss, 유료 PRO 판매, 구독 강제 적용은 현재 비결제 준비 빌드에서 보류되어 있습니다.

## 설치

### 시스템 요구사항

- **OS**: Windows 11 x64 (정식 지원)
- **메모리**: 4GB RAM (8GB 권장)
- **저장 공간**: 최소 50GB 여유 공간
- **그래픽카드**: NVIDIA NVENC (정식 지원). AMD/Intel/CPU는 실험적 폴백입니다.
- **인터넷**: YouTube 업로드를 위한 연결 필요

### 설치 단계

#### 1단계: 인스톨러 다운로드

1. [GitHub Releases 페이지](https://github.com/KhakiSkech/lolshorts/releases/latest)에서 최신 버전을 다운로드합니다.
2. 두 가지 인스톨러 중 선택:
   - **MSI 인스톨러** (권장): `LoLShorts_1.2.0_x64_en-US.msi`
   - **EXE 인스톨러**: `LoLShorts_1.2.0_x64-setup.exe`

#### 2단계: 설치 실행

1. 다운로드한 인스톨러를 더블클릭합니다.
2. 설치 마법사를 따릅니다.
3. 설치 완료 후 "LoLShorts 실행" 체크박스를 확인합니다. 설치/업데이트 동작은 공개 배포 전 별도 Windows 현장 검증이 필요합니다.

#### 3단계: 첫 실행

1. LoLShorts가 자동으로 실행됩니다.
2. 로그인 화면이 나타납니다.
3. 계정이 없으면 **"회원가입"** 버튼을 클릭합니다.

### 설치 위치

- **Windows**: `C:\Program Files\LoLShorts\`
- **데이터 폴더**: `C:\Users\[사용자명]\AppData\Roaming\lolshorts\`

**참고**: 배포 빌드는 FFmpeg 포함을 목표로 하지만, 실제 설치 패키지 포함 여부는 릴리스별 현장 검증으로 확인해야 합니다.

## 첫 사용

### 계정 설정

#### 회원가입

1. LoLShorts 실행
2. **"회원가입"** 클릭
3. 이메일 입력
4. 비밀번호 설정 (8자 이상)
5. **"가입"** 클릭

#### 로그인

1. 이메일 입력
2. 비밀번호 입력
3. **"로그인"** 클릭

### 기본 설정

#### 1단계: 비디오 설정

좌측 메뉴에서 **"설정"** → **"비디오"** 클릭:

| 설정 | 옵션 | 설명 |
|------|------|------|
| **해상도** | 720p / 1080p | 높을수록 품질 좋음, 파일 크기 증가 |
| **프레임레이트** | 30fps / 60fps | 60fps 권장 (더 부드러운 영상) |
| **비트레이트** | 낮음 / 중간 / 높음 | 인터넷 속도에 맞춰 선택 |
| **인코더** | 자동 선택 | NVIDIA/AMD/Intel 자동 감지 |

**권장 설정 (1080p 60fps)**:
- **해상도**: 1080p
- **프레임레이트**: 60fps
- **비트레이트**: 중간

#### 2단계: 오디오 설정

**설정** → **오디오** 클릭:

| 설정 | 옵션 | 설명 |
|------|------|------|
| **음성 입력** | 마이크 선택 | 음성해설 녹음 (선택사항) |
| **시스템 음성** | ON/OFF | 게임 음소거 켜짐 |
| **음량** | 0-100% | 게임 음성 크기 조절 |

#### 3단계: 이벤트 필터 설정

**설정** → **이벤트 필터** 클릭:

녹화할 이벤트를 선택합니다:

- ✓ **킬** (1점)
- ✓ **더블킬** (2점)
- ✓ **트리플킬** (3점)
- ✓ **쿼드라킬** (4점)
- ✓ **펜타킬** (5점)
- ✓ **바론 스틸**
- ✓ **드래곤 획득**
- ✓ **타워 파괴**

**팁**: 모든 이벤트를 켜두면 더 많은 클립이 생성됩니다.

## 게임 녹화

### 방법 A: 라이브 게임 녹화 (실시간)

#### 1단계: LoLShorts 실행

1. LoLShorts 앱을 실행합니다.
2. 로그인합니다.
3. **"녹화"** 탭을 클릭합니다.

#### 2단계: 녹화 시작

상태 표시판에서 자동 감지:

```
게임 상태: ⭕ 감지됨
녹화 상태: ⭕ 대기 중
```

**참고**: LoLShorts는 게임을 자동으로 감지합니다. 수동으로 시작할 필요 없습니다.

#### 3단계: 게임 플레이

1. 리그 오브 레전드를 실행하고 게임을 시작합니다.
2. 평상대로 게임을 진행합니다.
3. 킬, 바론 스틸 등 주요 이벤트가 발생하면 자동으로 녹화됩니다.

```
녹화 상태: 🔴 녹화 중 (30초)
```

#### 4단계: 게임 종료

게임이 끝나면:

1. LoLShorts가 자동으로 녹화를 중지합니다.
2. 클립이 처리됩니다 (30-60초 소요).
3. **"클립 라이브러리"** 탭에 클립이 나타납니다.

### 방법 B: 리플레이로 녹화 (과거 경기)

#### 1단계: 리플레이 탭 열기

좌측 메뉴에서 **"리플레이"** 클릭합니다.

#### 2단계: 게임 다운로드

1. 최근 게임 목록이 표시됩니다.
2. 원하는 게임을 찾습니다.
3. **"다운로드"** 버튼 클릭

```
다운로드 진행 중: ████████░░ 80%
```

다운로드 완료 후 상태가 변경됩니다:

```
상태: ✓ 다운로드됨 | [보기] 버튼 활성화
```

#### 3단계: 리플레이 재생

1. **"보기"** 버튼 클릭
2. 리그 오브 레전드 클라이언트에서 리플레이 재생

#### 4단계: 타겟 선택

게임이 로드되면 팝업이 나타납니다:

```
누구를 녹화하시겠습니까?
┌──────────────────┐
│ 🎮 Faker (봉사)  │
│ 🎮 Khan (상단)   │
│ 🎮 You (정글)    │
│ 🎮 Keria (서포)  │
│ 🎮 Gumayusi (원거) │
└──────────────────┘
```

원하는 선수를 클릭합니다.

**팁**: 유명 선수(페이커 등)를 선택하면 더 흥미로운 클립을 얻을 수 있습니다.

#### 5단계: 카메라 고정

게임 중 선택한 선수의 시점을 유지하려면:

- **더블클릭**: 선택한 챔피언 더블클릭
- 또는 **F1~F5**: 팀의 1번~5번 선수 고정

#### 6단계: 완성

게임이 끝나면 자동으로 녹화가 중지됩니다. **"편집기"** 탭에서 클립을 확인합니다.

## 클립 확인 및 편집

### 클립 라이브러리 확인

#### 1단계: 클립 라이브러리 열기

좌측 메뉴 → **"클립"** 클릭

#### 2단계: 클립 확인

```
┌─────────────────────────────────────┐
│ 게임 1 (2024년 3월 11일)            │
├─────────────────────────────────────┤
│ [클립 썸네일] 펜타킬 | 12초 | 5점   │ ← 삭제 | 편집
│ [클립 썸네일] 바론 스틸 | 8초 | 4점 │ ← 삭제 | 편집
│ [클립 썸네일] 더블킬 | 6초 | 2점   │ ← 삭제 | 편집
└─────────────────────────────────────┘
```

각 클립에는 다음 정보가 표시됩니다:

- **이벤트 유형**: 펜타킬, 바론 스틸, 더블킬 등
- **지속 시간**: 초 단위
- **우선순위**: 1-5점 (높을수록 중요)

### 수동 편집 (Editor)

#### 1단계: 편집기 열기

좌측 메뉴 → **"편집기"** 클릭

#### 2단계: 클립 선택

1. **"클립 추가"** 버튼 클릭
2. 라이브러리에서 원하는 클립을 선택합니다 (복수 선택 가능)
3. **"추가"** 클릭

#### 3단계: 포맷 선택

```
┌──────────────────────────┐
│ 포맷 선택                 │
├──────────────────────────┤
│ ◯ Shorts (세로 9:16)     │ ← YouTube Shorts 최적화
│ ◯ Montage (가로 16:9)    │ ← 몽타주 / 매드무비
└──────────────────────────┘
```

**Shorts vs Montage**:

| 포맷 | 화면비 | 용도 | 카메라 |
|------|--------|------|--------|
| **Shorts** | 9:16 (세로) | YouTube Shorts, TikTok | 자동 크롭 (챔피언 중심) |
| **Montage** | 16:9 (가로) | YouTube 일반, 매드무비 | 전체 화면 |

#### 4단계: 길이 선택

```
목표 길이:
◯ 60초 (빠른 하이라이트)
◯ 120초 (표준 몽타주)
◯ 180초 (풀 컴필레이션)
```

**권장**:
- **60초**: 빠르고 임팩트 있는 영상
- **120초**: 제일 무난한 길이
- **180초**: 장면이 많아야 함

#### 5단계: 클립 정렬 (선택사항)

클립을 드래그하여 순서를 변경합니다:

```
[펜타킬 12초] ⬆️
[더블킬 6초]  ⬇️
[바론 8초]
```

#### 6단계: 효과 추가 (선택사항)

**Canvas Overlay** (브랜딩):
- 채널명, 로고, 텍스트 추가
- [CANVAS_TUTORIAL.md](./CANVAS_TUTORIAL.md) 참고

**Background Music** (배경음악):
- 게임 음성 + 배경음악 믹싱
- [AUDIO_MIXING.md](./AUDIO_MIXING.md) 참고

#### 7단계: 미리보기

**"미리보기"** 버튼을 클릭하여 최종 결과를 확인합니다.

#### 8단계: 내보내기

```
┌──────────────────┐
│ 내보내기 옵션     │
├──────────────────┤
│ 파일명: My_Video │
│ 품질: 고화질     │
│                  │
│  [내보내기]      │
└──────────────────┘
```

**"내보내기"** 클릭:

1. 처리 시작 (지속 시간에 따라 1-5분 소요)
2. 완료되면 파일 탐색기가 자동으로 열립니다
3. 최종 .mp4 파일이 저장됩니다

**저장 위치**: `C:\Users\[사용자명]\Videos\LoLShorts\`

### 자동 편집 (Auto-Edit)

빠르게 동영상을 만들 수 있는 자동 편집 기능:

#### 1단계: Auto-Edit 열기

좌측 메뉴 → **"Auto-Edit"** 클릭

#### 2단계: 게임 선택

오늘 또는 이번 주의 게임 목록에서:

1. 최소 1개 이상 선택 (2-3개 권장)
2. 더 많은 게임 = 더 좋은 클립 선택

```
☑ 게임 1 (15분, 5 클립)
☑ 게임 2 (25분, 8 클립)
☑ 게임 3 (22분, 3 클립)
```

#### 3단계: 길이 선택

```
목표 길이:
60초 / 120초 / 180초
```

#### 4단계: 생성

**"생성"** 버튼 클릭:

```
처리 중... ████████░░ 65%
예상 시간: 45초 남음
```

완료되면 자동으로 편집기에서 열립니다.

## YouTube 업로드

### 1단계: YouTube 계정 연결

좌측 메뉴 → **"YouTube"** 클릭

#### 첫 번째 업로드 시 인증:

1. **"YouTube 계정 연결"** 버튼 클릭
2. 브라우저에서 Google 로그인 페이지가 열립니다
3. YouTube 계정 선택
4. **"LoLShorts이 계정 접근을 요청"** 허가
5. 설정된 테스트 환경에서는 자동으로 LoLShorts로 돌아올 수 있습니다. 실제 YouTube 계정 동작은 별도 현장 검증이 필요합니다.

```
연결 상태: ✓ 연결됨
계정: your-email@gmail.com
```

### 2단계: 비디오 선택

1. **"업로드"** 탭 클릭
2. 업로드할 비디오 선택
3. **"다음"** 클릭

### 3단계: 메타데이터 입력

```

```

**"업로드"** 클릭:

```
업로드 진행 중... ████████░░ 72%
예상 완료: 45초 남음

파일 크기: 125MB
업로드 속도: 5 Mbps
```

### 5단계: 완료

업로드 완료 후(실제 YouTube 계정 검증이 완료된 환경에서만 주장 가능):

```
✓ 업로드 완료!

비디오 링크:
https://youtu.be/dQw4w9WgXcQ

[링크 복사] [채널에서 보기]
```

**참고**: YouTube 처리에 몇 분이 걸릴 수 있습니다. 영상 재생 가능 여부를 확인하세요.

```

- 1080p (권장)
- 1440p (느림, 높은 품질)
```

## 문제 해결

### Q1: "게임을 감지하지 못했습니다"

**원인**: LoL 클라이언트가 실행되지 않거나 포트 2999가 차단됨

**해결방법**:
1. League of Legends 클라이언트를 먼저 실행합니다
2. **설정** → **일반** → **자동 감지** 확인
3. 혹은 게임 시작 후 30초 대기

```
게임 감지 상태:
⏳ 대기 중... (30초)
```

**고급**: 방화벽이 포트 2999를 차단하는 경우
- Windows 방화벽 → 고급 설정 → 인바운드 규칙
- 포트 2999 TCP 허용

### Q2: "FFmpeg 오류가 발생했습니다"

**원인**: FFmpeg 바이너리 손상 또는 누락

**해결방법**:
1. LoLShorts 제거
2. `C:\Users\[사용자명]\AppData\Roaming\lolshorts\` 폴더 삭제
3. 최신 인스톨러 다시 다운로드 및 설치

### Q3: "녹화 중에 렉이 발생합니다"

**원인**: GPU 인코딩이 작동하지 않거나 CPU 부하 과다

**해결방법**:

#### 1단계: GPU 설정 확인
```
설정 → 비디오
인코더 확인: NVIDIA (또는 AMD/Intel)
```

#### 2단계: 해상도 낮추기
```
설정 → 비디오
해상도: 1080p → 720p 변경
```

#### 3단계: 백그라운드 프로그램 종료
- Discord, OBS, 스트리밍 소프트웨어 종료
- CPU 사용률 확인: Windows 작업 관리자

#### 4단계: 드라이버 업데이트
- **NVIDIA**: GeForce Experience에서 드라이버 업데이트
- **AMD**: Radeon Software에서 드라이버 업데이트
- **Intel**: Intel Arc Control에서 드라이버 업데이트

### Q4: "클립이 저장되지 않습니다"

**원인**: 저장 공간 부족 또는 파일 권한 문제

**해결방법**:

#### 1단계: 저장 공간 확인
```
설정 → 스토리지
최소 50GB 여유 공간 필요
```

#### 2단계: 불필요한 파일 삭제
```
C:\Users\[사용자명]\Videos\LoLShorts\
오래된 클립 수동 삭제
```

#### 3단계: 폴더 권한 확인
```
C:\Users\[사용자명]\Videos\ 우클릭
→ 속성 → 보안 → 편집
[사용자] 모두 체크
```

### Q5: "YouTube 업로드가 계속 실패합니다"

**원인**: 네트워크 문제 또는 인증 만료

**해결방법**:

#### 1단계: 재인증
```
YouTube 탭 → 계정 → [다시 연결]
```

#### 2단계: 파일 크기 확인
- YouTube는 최대 256GB 지원하므로 문제 없음
- 하지만 인터넷이 느리면 시간이 오래 걸림

#### 3단계: 네트워크 확인
- 인터넷 속도 확인: speedtest.net
- 최소 5Mbps 권장
- WiFi보다 유선 연결 권장

#### 4단계: YouTube 할당량 확인
- 몇 시간마다 업로드하면 일일 할당량 초과 가능
- 24시간 후 다시 시도

### Q6: "자막/오버레이가 깨집니다"

**원인**: 폰트 설정 또는 해상도 불일치

**해결방법**:

#### Canvas Overlay 문제:
```
편집기 → Canvas → 폰트 설정 확인
```

#### 권장 설정:
- **포맷**: Shorts (9:16)는 세로 제목 사용
- **폰트**: 한글은 "나눔고딕" 또는 "맑은 고딕"
- **크기**: 텍스트가 안 잘리려면 50px 이상

### Q7: "앱이 자주 깝니다 (튕깁니다)"

**원인**: 메모리 부족 또는 잘못된 설정

**해결방법**:

#### 1단계: 로그 확인
```
C:\Users\[사용자명]\AppData\Roaming\lolshorts\logs\app.log
최근 에러 메시지 확인
```

#### 2단계: 설정 초기화
```
설정 → 일반 → [설정 초기화]
```

#### 3단계: 재설치
```
제어판 → 프로그램 제거 → LoLShorts 제거
최신 버전 다시 설치
```

### Q8: "구독 기능이 작동하지 않습니다"

**원인**: 현재 빌드에서는 결제, Toss, 유료 PRO 판매, 구독 강제 적용이 보류되어 있습니다.

**해결방법**:

#### 1단계: 무료 로컬 워크플로 사용
- 로컬 녹화, 편집, 내보내기 워크플로를 사용합니다.
- 유료 결제 또는 Toss 결제 기록 확인은 현재 지원 경로가 아닙니다.

#### 2단계: 준비 상태 문서 확인
- FREE/PRO 정책은 문서 수준 정책이며, 결제 QA와 지원 검증 이후에만 활성화될 수 있습니다.

## 팁 & 트릭

### 1. 고품질 하이라이트 만드는 팁

✓ **펜타킬 > 쿼드라킬 > 트리플킬** 순으로 우선순위
✓ **같은 게임의 클립 섞기**: 스토리 만들기 좋음
✓ **음악과 클립 맞추기**: BPM에 맞춰 편집

### 2. YouTube 성공 팁

✓ **제목에 챔피언명 포함**: "모데카이저 5K" vs "킬 영상"
✓ **썸네일은 눈에 띄게**: 큰 텍스트, 밝은 색상
✓ **설명에 해시태그 최소 3개**: #LeagueOfLegends #LoL #하이라이트
✓ **정기적 업로드**: 일주일에 2-3개 추천

### 3. 고급 편집 팁

✓ **120초 영상이 가장 인기**: 길지 않고 짧지 않음
✓ **첫 5초가 중요**: 펜타킬이나 멋진 장면으로 시작
✓ **전환 효과 최소화**: 음악만 해도 충분
✓ **자막은 선택적**: Canvas 오버레이는 브랜딩 용

### 4. 저장 공간 절약

```
자동 정리 활성화:
설정 → 스토리지 → ☑ 7일 이상된 미사용 클립 자동 삭제
```
